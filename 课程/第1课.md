# 第 1 课 · Type-1 与三个角色

这是第一课。本课只解决两件事：**Gunyah 在硬件上的位置**，以及 **RM / PVM / SVM 谁管谁**。

---

## 1. Type-1：底下没有宿主 Linux

Hypervisor 有两种常见摆法：

![Type-1 与 Type-2](图/第1课-Type1对比.svg)

| | Type-2 | Type-1（Gunyah） |
|--|--------|------------------|
| 底下有没有完整宿主 OS | 有（Windows / Linux 等） | **没有** |
| Hypervisor 自己是什么 | 宿主上的一个进程 | 直接占硬件、跑在更高特权级 |
| 你装的 Linux 是什么 | 可以是宿主，也可以是客户机 | **一定是客户机** |

Gunyah 的说明书原话：它独立于任何高层 OS 内核（如 Linux），跑在比 VM 更高的 CPU 特权级上；核心功能不依赖更低特权的 OS。这就是 Type-1。

本仓库 `gunyah-hypervisor` **只是 EL2 上的那一层**。完整系统通常还要另三个仓库：Resource Manager、C Runtime、support-scripts。缺 RM 时，你只有「能隔离的内核」，没有「谁来建 VM、怎么分资源」的策略。

Gunyah 还偏微内核：自己只做隔离、调度、内存归属这类关键服务，非关键策略尽量下放。下放给谁，就是下一节的 Root VM。

## 2. 谁管谁：RM(Resource Manager) / PVM (Primary VM) / SVM (Secondary VM)

![Gunyah 在系统里的位置](图/第1课-层级.svg)

四个词，先分开，不要混：

| 词 | 全称 | 它是谁 | 它不是谁 |
|----|------|--------|----------|
| **Gunyah** | 本仓库的 Hypervisor | 跑在 EL2 的 Type-1 | 不是 Linux，也不是 RM |
| **Root VM / RM** | Resource Manager | 第一个 VM；策略 / 建 VM / 管资源 | 不是 Hypervisor 本身 |
| **PVM / HLOS** | Primary VM / High Level OS | 主系统所在 VM，通常就是里面的 Linux | 不是「整机的宿主 OS」 |
| **SVM** | Secondary VM | 次级虚拟机，一般由 **PVM 侧发起创建** | 不是 RM |

谁管谁，记这一条链：

```text
硬件
 └─ EL2：Gunyah（机制：隔离、VCPU、内存、中断）
      └─ Root VM：Resource Manager（策略：谁能建 VM、资源怎么分）
           ├─ PVM / HLOS：主 Linux
           └─ SVM：由 PVM 侧发起创建的次级 VM
```

| 常见误区 | 正确说法 |
|----------|----------|
| 板上那份 Linux 就是 hypervisor | 那份 Linux 是 **PVM**。它权限高、设备多，但仍是 EL2 下面的**客户机** |
| RM 很特权，所以它就是 hypervisor | **RM 也是 VM**。它是策略引擎，比 PVM/SVM 管得宽，但仍然坐在 Gunyah 之上，并不代替 Gunyah |

`docs/terminology.md` 里 HLOS 常常当作 PVM 的同义词：主 OS、占大部分硬件访问。SVM 则写明是 *created and launched from the PVM*。

---

## 本课你要带走的三句话

1. **Gunyah 是 Type-1**：直接跑在硬件 / EL2 上，底下没有宿主 Linux。
2. **本仓库只是 EL2 核心**；建 VM、分资源的策略在 Root VM 里的 Resource Manager。
3. **PVM 是主 Linux，SVM 由 PVM 侧发起创建**；两者都是客户机，不是 hypervisor。Gunyah才是hypervisor。

## 小练习

请用自己的话回答下面两题（一两句就行）：

1. 有人把 VirtualBox 和 Gunyah 都叫「虚拟机软件」。对 Type-1 / Type-2 来说，关键差别是哪一句？
2. 设备上那份主 Linux 是 PVM 还是 hypervisor？SVM 一般由谁发起创建？

回答：
1.关键在于他们底下是否还包含了os这个级别，virtualbox是要运行到操作系统上的，而gunyah是直接跑到裸金属机器上的。
2.是pvm。SVM 一般由 PVM 侧发起创建。

答完后，下一课只拆一个词：**EL2**——EL0 / EL1 / EL2 各跑什么。
